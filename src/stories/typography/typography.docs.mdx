# Typography

The `Typography` provides a consistent set of text styles for headings, paragraphs, and inline elements, ensuring clear hierarchy, readability, and brand-aligned communication across the interface.

### Usage

```
import { Typography } from "cleanplate";

const App = () => {
  return (
    <Typography
      variant="h1"
      isBold={true}
      align="center"
      wordBreak="normal"
    />
  );
}
```

### Type scale

UI 12–24px (4px grid + 14px). Display 32 / 40 / 48 (Major Third from 24). `h4`–`h6` reuse UI sizes.

| variant | Size | Line-height | Weight | Tracking |
| --- | --- | --- | --- | --- |
| `h1` | 48 | 56 | 700 | −0.03em |
| `h2` | 32 | 40 | 700 | −0.02em |
| `h3` | 24 | 32 | 700 | −0.015em |
| `h4` | 20 | 28 | 600 | 0 |
| `h5` | 16 | 24 | 600 | 0 |
| `h6` | 14 | 20 | 600 | +0.01em |
| `p` / `span` | 16 | 24 | 400 | 0 |
| `small` | 12 | 16 | 400 | +0.01em |
