# PageHeader

The `PageHeader` component provides a two-column page header: **left** (title and optional subtitle) and **right** (primary CTA and optional more menu with a three-dots icon). Use it at the top of a page or section to show the heading and main actions. The right column is aligned to the right edge.

## Features

- **Title:** Required; string or custom ReactNode (left column)
- **Subtitle:** Optional; string or ReactNode below the title (left column)
- **Primary CTA:** Optional `PageHeaderCtaConfig` object (not a render function). Both breakpoint buttons are rendered; CSS shows one at 600px. Wider than 600px: labeled button, `icon` as a prefix. Up to 600px: a resolved `icon` becomes an icon button (`aria-label` is `label`) unless `mobile.variant` is set. `desktop` / `mobile` override `label`, `icon`, `variant`, and `size`. A ReactNode renders once, as-is.
- **More menu:** Optional; either `moreMenuItems` (list of objects with `label` and `onClick`) or `moreMenuContent` (custom ReactNode). Renders a trigger with the Material **more_vert** (three vertical dots) icon and a dropdown (right column)
- **Layout:** Flex row that does not wrap. Title and subtitle ellipsize on one line. Actions stay on the right (`margin-left: auto`). Below 600px the actions column reserves one medium icon button, or two when both the primary action and the more menu are present.
- **Margin:** Suffix spacing. Default `b-4` (16px below the header). Pass `margin="0"` to remove it.
- **className:** Optional root class

## Usage

```jsx
import { PageHeader } from "cleanplate";

const Page = () => (
  <PageHeader
    title="Dashboard"
    subtitle="Overview of your projects"
    primaryCta={{
      label: "Create project",
      icon: "add",
      onClick: () => createProject(),
    }}
    moreMenuItems={[
      { label: "Export", onClick: () => exportData() },
      { label: "Settings", onClick: () => openSettings() },
    ]}
  />
);
```

## Examples

### Full header

Title, subtitle, a responsive primary action, and more menu. `icon` is a prefix on desktop and an icon button up to 600px.

```jsx
<PageHeader
  title="Projects"
  subtitle="Manage and track your team projects"
  primaryCta={{
    label: "New project",
    icon: "add",
    onClick: () => {},
  }}
  moreMenuItems={[
    { label: "Export", onClick: () => {} },
    { label: "Archive", onClick: () => {} },
    { label: "Settings", onClick: () => {} },
  ]}
/>
```

### Title and subtitle only

No actions; useful for read-only or simple pages.

```jsx
<PageHeader
  title="Settings"
  subtitle="Configure your account and preferences"
/>
```

### With primary CTA only

```jsx
<PageHeader
  title="Documents"
  subtitle="All your documents in one place"
  primaryCta={<Button>Upload</Button>}
/>
```

### With more menu only

```jsx
<PageHeader
  title="Report"
  subtitle="Generated on 17 Feb 2025"
  moreMenuItems={[
    { label: "Print", onClick: handlePrint },
    { label: "Download PDF", onClick: handleDownload },
    { label: "Share", onClick: handleShare },
  ]}
/>
```

### Custom title or subtitle (ReactNode)

Pass custom elements for title or subtitle instead of strings.

```jsx
<PageHeader
  title={
    <Container display="flex" align="center" gap="2" padding="0" margin="0">
      <Icon name="assignment" size="medium" />
      Custom title with icon
    </Container>
  }
  subtitle={
    <Container display="flex" align="center" gap="1" padding="0" margin="0">
      <Icon name="info" size="small" />
      Subtitle can be custom too
    </Container>
  }
  primaryCta={<Button>Action</Button>}
/>
```

### Custom more menu content

Use `moreMenuContent` for full control over the dropdown content (e.g. links, dividers, custom markup).

```jsx
<PageHeader
  title="Page"
  primaryCta={<Button>Save</Button>}
  moreMenuContent={
    <div style={{ padding: "8px" }}>
      <a href="/export">Export</a>
      <hr />
      <button type="button">Settings</button>
    </div>
  }
/>
```

### With Container

```jsx
<Container padding="4" width="full">
  <PageHeader
    title="Dashboard"
    subtitle="Welcome back"
    primaryCta={<Button>Create</Button>}
    moreMenuItems={[{ label: "Help", onClick: () => {} }]}
  />
</Container>
```

## Behavior

- **Layout:** Root is a `<header>`. Inside, a flex row (`.cp-page-header-row`) does not wrap: start is a column (title above subtitle) and actions sit on the right (`margin-left: auto`). Title and subtitle ellipsize when space runs out. Below 600px the actions column reserves the width of one medium icon button, or two when both the primary action and the more menu are present.
- **Title / subtitle:** Rendered with Typography (`h4` for the title, `small` for the subtitle). Each is one line and ellipsizes when the actions need the remaining width.
- **Margin:** Suffix API. Default `b-4`.
- **Primary CTA:** Pass a `PageHeaderCtaConfig` object, not a function of the viewport. Both breakpoint buttons are rendered; CSS hides one at 600px (`--mobile-breakpoint`) so server HTML matches the client. Wider than 600px it is a labeled button (`variant` default `solid`) and `icon` is a prefix. Up to 600px, a resolved icon switches it to an icon button whose `aria-label` is `label`; the base `variant` is ignored unless `mobile.variant` is set. No icon keeps the labeled button at both sizes. `desktop` and `mobile` override `label`, `icon`, `variant`, and `size` for that breakpoint. A React element is rendered once, unchanged.
- **More menu:** When `moreMenuItems` is provided, the component renders a Dropdown with an icon Button (more_vert) and a list of buttons; each item’s `onClick` runs and the dropdown closes. When `moreMenuContent` is provided, that content is rendered inside the dropdown panel. Only one of `moreMenuItems` or `moreMenuContent` should be used.
- **Accessibility:** More trigger has `aria-expanded` and `aria-haspopup`; list uses `role="menu"` and `role="menuitem"`.
