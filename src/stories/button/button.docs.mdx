# Button

The `Button` component is a customizable action trigger for user interactions. It supports multiple visual variants, size options, loading and disabled states, fluid width mode, prefix/suffix icons, and margin spacing utilities.

## Features

- **Variants:** `solid`, `outline`, `ghost`, and `icon`
- **Sizes:** `small`, `medium`, and `large`
- **Icons:** `prefixIcon` and `suffixIcon` (Material Symbol names)
- **States:** `isLoading` and `isDisabled`
- **Layout:** `isFluid` for full-width buttons
- **Spacing:** `margin` accepts spacing utility token(s)
- **Type-safe defaults:** `type="button"` to prevent accidental form submit

## Usage

```jsx
import { Button } from "cleanplate";

const App = () => (
  <Button variant="solid" size="medium" onClick={() => console.log("clicked")}>
    Save changes
  </Button>
);
```

## Examples

### Variants

```jsx
<>
  <Button variant="solid">Solid</Button>
  <Button variant="outline">Outline</Button>
  <Button variant="ghost">Ghost</Button>
  <Button variant="icon" prefixIcon="close" aria-label="Close" />
</>
```

### Prefix and suffix icons

```jsx
<>
  <Button prefixIcon="add">Next</Button>
  <Button suffixIcon="expand_more">Export</Button>
  <Button prefixIcon="add" suffixIcon="expand_more">Create</Button>
</>
```

### Sizes

```jsx
<>
  <Button size="small">Small</Button>
  <Button size="medium">Medium</Button>
  <Button size="large">Large</Button>
</>
```

### Loading and disabled states

```jsx
<>
  <Button isLoading>Loading...</Button>
  <Button isDisabled>Disabled</Button>
</>
```

### Fluid width

```jsx
<Button isFluid>Full width button</Button>
```

### Margin spacing

```jsx
<>
  <Button margin="2">Single margin token</Button>
  <Button margin={["1", "b-3"]}>Multiple margin tokens</Button>
</>
```

### Form submit button

```jsx
<form
  onSubmit={(e) => {
    e.preventDefault();
    console.log("submitted");
  }}
>
  <Button type="submit">Submit</Button>
</form>
```

## Behavior

- When `isLoading` is true, a loading icon replaces the prefix slot and the button is disabled.
- When `isDisabled` is true, click events are prevented and native `disabled` is applied.
- If both `isDisabled` and `isLoading` are true, the button stays disabled and shows loading.
- `onClick` is not invoked while disabled/loading, even if an event reaches the element.
- `margin` accepts a token string or array of tokens (for example `"2"` or `["1", "b-3"]`).
- `variant="icon"` is a visual style. Icon-only buttons are **square** at the size height (32 / 44 / 52). Provide an accessible name via `aria-label`.
- `prefixIcon` / `suffixIcon` inherit button text color. Glyph sizes are 16 / 20 / 24 px per size.
- Form controls remain 50px tall. Use `size="large"` on buttons placed beside inputs.
